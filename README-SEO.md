## 🆘 Troubleshooting

### Issue: Files not accessible
**Solution:** Ensure they're in `/public` folder and server is running.

### Issue: AI doesn't mention business
**Solution:** Wait 2-4 weeks for crawling. Ensure robots.txt allows bots.

### Issue: Wrong information in AI responses
**Solution:** Update ai.txt immediately and revalidate structured data.

### Issue: Low search rankings
**Solution:** Need more content, backlinks, and reviews. This takes 2-3 months.
