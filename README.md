## Admin and Client Portal

Set these server-side environment variables before signing in:

- `ADMIN_USER` and `ADMIN_PASS` for `/admin` (there is no default admin password).
- `PORTAL_SESSION_SECRET` to a long, random value for signing client and staff sessions. If omitted, the portal uses `ADMIN_PASS` as its signing key.
- `MONGODB_URI` for the MongoDB database used by the site, portal accounts, and support issues.

Sign in to `/admin`, open **Client & Staff Portal**, and create client or staff accounts. Give each person their email and initial password directly. Clients can sign in at `/portal` to submit issues and follow updates; staff use the same page to assign requests and manage status. Portal account passwords are stored as scrypt hashes.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
